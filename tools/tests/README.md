# 確認用プログラム

外部サービス（日程・天気・位置検索）は差し替えて、全国の駅で「行き方」が動くか、画面が使いやすいかを確かめます。

準備：全国の駅の一覧（都道府県つき）を作る（`make_stations.py` の説明どおり）→ `stations-test.json`

1. `node tools/tests/logic.test.mjs "$PWD" stations-test.json`（画面を使わない確認）
   - 全駅 × 国内の全会場で、乗り換えのURLに日付・時刻・出発/到着が正しく入るか
   - 会場の到着駅・駅までの距離が、駅の一覧と合っているか／カーナビ・マップのURL
   - 全駅のそばを現在地にして、一番近い駅が選ばれるか（約2万件）
   - 駅から遠い山の中・鉄道のない島での動き／全駅が国内、国外15都市が国外と判定されるか
   - 一覧の取り出し方（これから・過去・日程未定・開催中・次の予定・申込締切・月ごと・種類の色・二重の予定）
2. `node tools/tests/ui.test.js "$PWD" stations-test.json`（Playwright が必要。`N=10` で出発地を減らせる）
   - 下のボタンが、どの画面・どの大きさでも画面の一番下に固定されるか
   - 不要にした機能（地図・Googleマップ・説明文・はじめての方へ・期限タブ）が残っていないか
   - 予定の一覧が Event list と同じ作りか（タブ・帯・月の帯・行・過去・日程未定）
   - 詳細の開き閉じ（×・Escape・外側・「戻る」）、国内の全会場・海外・未登録・オンライン
   - 乗り換えの日付・時刻（入力・iPhone の change だけ・出発/到着・空・同じ駅・開き直し）
   - 現在地から出発駅（47都道府県×3か所・圏外・許可なし・海外・鉄道のない島）
   - 外のアプリを開いて戻る／裏へ行って戻る／読み込み直し（通信あり・圏外）／新しい版への切り替え
   - 読み込み失敗・圏外・バックアップの読み込み
   - 文字は12px以上、押す所は40px以上、入力欄は16px以上、色の差は4.5:1以上、幅 320〜430px ではみ出さない

※ 外部サービスの応答は差し替えています。実際の Yahoo!乗換案内などが返す内容は、ここでは確かめていません。
