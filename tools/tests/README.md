# 確認用プログラム

外部サービス（日程・天気・地図・駅探し・経路）を使わずに、全国の駅で「行き方」が動くかを確かめます。

1. 全国の駅の一覧を作る（`make_stations.py` の説明どおり）
2. `node tools/tests/logic.test.mjs "$PWD" stations.json`
   - 全 8,878駅 × 国内の全会場で、乗り換え案内のURL（Yahoo!・Google・Apple）を確認
   - 全駅で「国内」と判定されるか、国外の15都市が「国外」になるか
   - 全駅の近くを現在地にして、一番近い駅が選ばれるか
   - 駅から遠い山の中で、探す範囲を広げて駅が見つかるか
3. `node tools/tests/ui.test.js "$PWD" stations.json`（Playwright が必要）
   - 47都道府県から3駅ずつ（141駅）を現在地にして、画面で「現在地の最寄り駅」→「Yahoo!乗換案内で検索」、駅名の入力、車の経路を押して確認
   - 国内の全会場・海外の会場・未登録の会場・オンライン配信・海外にいるとき・入力なし
   - 地図の会場一覧、幅 320 / 375 / 430px で横にはみ出さないか

※ 外部サービスの応答は差し替えています。実際の Yahoo!乗換案内などが返す経路の中身は、ここでは確かめていません。
